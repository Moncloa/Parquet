# Parquet runtime channel

This branch and pull request exist only as a private runtime message bus between the Parquet LXC and ChatGPT.

Do not merge or close the pull request while the GitHub runtime bridge is in use.

Runtime comments use these markers:

- `[PARQUET:REVIEW_REQUEST]` for Parquet -> ChatGPT requests.
- `[PARQUET:ANALYSIS]` for ChatGPT -> Parquet responses.

No secrets belong in comments. Runtime data may contain sensitive market/portfolio context, so the repository must remain private.
